## ✨ Features & Architecture

- **Luxury Aesthetic:** Tailored Indian wedding palette with obsidian surfaces and champagne gold accents (`#D4AF37`).
- **Interactive Gallery & Lightbox:** Filter between Weddings, Candid, Pre-Wedding, Rituals & Haldi, and Films with high-resolution modal preview.
- **Services Catalog:** Detailed service cards for Candid Photography, 4K Cinematic Films, Pre/Post-Wedding shoots, Traditional Rituals, and Bespoke Albums.
- **Embedded Google Maps & GPS Navigation:** Working "Get Directions" button that opens live Google Maps navigation directly to the Karimnagar studio.
- **Interactive Inquiry Modal:** Direct WhatsApp integration pre-formatting client requests with celebratory confetti.
- **Mobile-Responsive:** Sticky glassmorphic navbar and fixed bottom mobile action bar (Call, WhatsApp, Directions, Book).

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript

- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
